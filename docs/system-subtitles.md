# 视频与直播的本机双语字幕

1. 设置中准备 Whisper 和本机 LLM。创建课程，并填写视频或直播的课堂名称。
2. 课堂页面把“声音来源”切换为“系统声音 · 视频 / 直播”。在语言设置中选英语（英译中）或中文（中译英）。
3. 点击开始课堂，再播放视频或进入直播。macOS 出现系统共享选择器时，选择屏幕并允许共享系统音频。软件不采集麦克风；需要老师的本地话筒时使用麦克风模式。
4. 置顶双语字幕窗自动打开。可拖动顶部/字幕区域、拖动边缘缩放、调整字号。隐藏浮窗不会停止录制；“返回课伴”可暂停、继续或结束课堂。
5. 结束课堂停止系统声音采集，等待尾句及翻译保存。录音和双语文字在所属课程的资料库中，可继续生成总结、思维导图，或导出 SRT。

字幕是按停顿和短段持续生成的，本机识别与翻译需要时间；实际延迟受模型和设备影响。原文与译文始终配对。翻译跟不上说话时显示待翻译句数，并继续呈现最新完成的一组双语字幕。

Windows 使用 Chromium/WASAPI 系统音频回采。macOS 系统声音功能要求 14.2+，15+ 使用系统共享选择器；14.0/14.1 仍可使用麦克风课堂。首次请在系统提示中授权课伴；拒绝后可通过系统设置 → 隐私与安全性 → 屏幕与系统音频录制正常授权，必要时重新打开软件。

浏览器、播放器或会议的声音必须输出到当前系统音频输出设备。选择窗口并不保证只采集该窗口的声音：系统回采可能包含其他同时播放的应用。软件只将音轨送入 Whisper 和录音，不保存屏幕画面，不上传课文。暂停视频、设备静音或权限未成功时，软件会提示未检测到系统声音。没有音轨时不会退回麦克风。

受 DRM 保护的视频、应用主动禁止捕获的声音、Windows 独占全屏游戏/播放器或其他更高层级窗口，可能无法正常采集或显示字幕。可用播放器的窗口或无边框全屏模式。

测试证据分开记录：Windows 使用受控外部 WAV 播放完成真实系统回采与本机模型测试；macOS 在原生 arm64/x64 runner 中验证权限声明、安装包、浮窗和合成系统音轨链路。合成音轨测试不等于物理 MacBook 的音频设备或系统授权已经实测。
